# My Harbor Scripts
My scripts for the Harbor Stremio client for personal use

### script.js
This script does 3 things to the player in Harbor - 
1. It makes mouse right clicks simple play or pause only, no context menu
2. It removes play pause functionality from the left click but retains default double click to full-screen and click to drag functionality
3. It lets you configure and use a keyboard shortcut to use the context menu if needed
